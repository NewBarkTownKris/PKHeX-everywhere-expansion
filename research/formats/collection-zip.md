# Collection ZIP exports

**Status:** download containers, not input save formats. The native expansion collection exporter in [NativeCollectionArchive.cs](../../src/PKHeX.Everywhere.RomHacks/Expansion/NativeCollectionArchive.cs), state exporter in [StateExport.cs](../../src/PKHeX.Everywhere.RomHacks/Expansion/StateExport.cs), and Quetzal exporter in [QuetzalArchive.cs](../../src/PKHeX.Everywhere.RomHacks/Quetzal/QuetzalArchive.cs) implement distinct archive variants. Inspect the relevant implementation rather than assuming the same directory names or contents across all three.

Where available, archives include individual portable Pokémon, native/raw source records or metadata, and descriptions of mappings or approximations. Native expansion collections can also include a newer regional alternative to a PK4. Quetzal's per-Pokémon metadata is particularly important for approximate trainer, ball and location values and original flags. Keep metadata with exported files: PK formats alone cannot always carry hack-specific ball IDs, Radiant status, original met locations or source PID. ZIP output is not a promise that all extracted Pokémon are legal in the destination game.
