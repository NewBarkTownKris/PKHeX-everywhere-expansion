# Pokémon Liquid Crystal — experimental export

**Earlier status:** local investigation and experimental generic FireRed-sector reader before the update below. The supplied `.sa1` was 65,536 bytes of `FF`; it contains no save data. The candidate ROM's SHA-256 is `adc4dbddd285b55261ba01a3d531d2df19c892515c3f41043566b0737ca3ba5d`. Do not include the ROM or personal files in this repository.

The local [HistoricGen3 reader](../../src/PKHeX.Everywhere.RomHacks/Historic/HistoricGen3.cs) has synthetic FireRed-sector party/PC, blank-file and corrupt-slot checks, and was subsequently checked against one fresh, game-created Cyndaquil party record from this exact ROM, saved and reloaded in mGBA. Its 100 bytes matched the live party at `0x02024284`, checksum valid; native species 155, level 5, met ID 143 mapped to New Bark Town. This does not validate PC records or other species. The ROM's name-pointer table at `0x2C8980` was found in code that indexes it as `nativeMapSection - 0x58`; [candidate place table](../../src/PKHeX.Everywhere.RomHacks/Historic/liquid-crystal-places.json) includes 102 unique name matches among 165 entries to HG/SS, including New Bark, Cherrygrove and Route 29. Exact IDs and name matches are revision-specific; unmatched or ambiguous places need review and the original native ID must remain available.

The candidate [species/move table](../../src/PKHeX.Everywhere.RomHacks/Historic/liquid-crystal-tables.json) was read from this ROM, including Gen 4 species at native IDs 252–276. Names do not prove full species/form/ability/item semantics. Proposed portability: use HG/SS place names where representable, or a clearly labeled region/unknown fallback. Ball and shiny mapping are **not yet established**; do not import a Quetzal, CFRU or expansion rule by analogy. Obtain additional real matching `.sav` or `.sgm` examples, compare native game getters and record codecs, and validate eggs, ID mappings and edited/save-state behavior before shipping.

## Local experimental export update (2026-10-29)

The later-supplied folder includes a different, nonblank `.sa1` and eight VBA 9 states for the exact ROM above. The `.sa1` contains checksum-bearing FireRed sectors 1–13 scattered across a 64 KiB flash image, but sector 0 is missing. A read-only partial-flash recovery can extract party and PC while explicitly reporting the missing trainer/settings sector; it does not generate an edited save. Its party and all 33,604 PC-storage bytes match the latest 2026 state byte-for-byte, so that state provides a separate source of the missing live context. All eight supplied states decoded successfully (41–60 records); the most recent had 60 official-species records across party and PC. Private data and fixtures remain outside this repository.

`ClassicRecovered` adds explicitly selected VBA 9 live party/PC export and complete FireRed battery-save export; the user must select the correct revision because the game header is shared. Species and moves map from the exact source ROM's name tables, including explicit standard renaming for Farfetch'd and Faint Attack. This does not establish modified mechanics or forms in all cases; eggs and unidentified species are skipped, and unknown moves retain native-only records. Unown forms use PID-derived Gen 3 decoding. Portable PK6 files assume standard PID shininess, abilities and gender; all held items are dropped and balls become Poké Balls because source semantics remain unverified. Party EXP is adjusted where needed to preserve the game's displayed level; box levels use standard growth data and may differ. Name-matched HG/SS locations become Johto or Kanto **regional** PK6 locations; unmatched locations are unknown. Native records, original EXP, ball, held item, PID, OT and met ID remain in metadata. The user-selected state is read-only; no edit/repack support is claimed. Synthetic tests cover PC position, pointer rejection, original-byte preservation and the two name exceptions. Browser chooser/download testing remains outstanding.

Exact-build mGBA version 7 state extraction is also implemented for party and PC. A fresh game-created starter state matched its saved native party record and portable identity; PC coverage uses synthetic fixtures, not a real mGBA PC. Exact ROM CRC identification is required.

Partial-flash recovery update: the 13 present sectors passed checksums and all 60 native Pokémon records matched the separately supplied latest VBA state byte-for-byte. A zeroed internal placeholder lets the standard reader inspect the intact sectors, but is never exported as a save and is not used as a trainer identity. Synthetic checks reject incomplete Dark Rising images and exercise this Liquid Crystal case.
