# Pokémon Cobalt Blue US — local compatibility

## Scope and evidence

Read-only PK2 recovery from a user-selected in-game save or an exact-build mGBA live-party state for the supplied Game Boy Color ROM (SHA-256 prefix `28fd58d44634`). The generic Generation 2 save has no trustworthy hack identifier; selecting the wrong game can produce misleading results. The original supplied 32,812-byte file did not load as a saved game in mGBA and is not recovered. A fresh game was instead started in the supplied ROM; its Pikachu was obtained, saved in-game and reloaded in mGBA. The inherited PKHeX `SAV2` reader reports valid checksums, and the local exporter produced a PK2 preserving the starter's species, nickname, trainer, ID, level and moves. A fresh, synthetic boxed Pokémon checked occupied-PC slot handling and an export archive. An mGBA raw state for CRC `6C8DD2E8` also yielded the same starter from live GB work RAM (serialized core party offset `0x5E22`); state export covers the party only. Other real creatures, shiny behavior, party/PC changes from gameplay and save editing remain unverified.

## Mapping and safety

The ROM species-name table begins at `0x1B0B74`, with 10-byte entries. All 251 original Gen 2 species IDs have matching official names; such matches do not prove unchanged forms or mechanics. The variable-length move-name table at `0x1B1574` has 239 exact standard-name matches; other move IDs are skipped until separately mapped. Pokémon using unmatched moves, invalid species or eggs are skipped. The game-displayed Pikachu starter held an item named `FRUIT` at native ID 173; in standard Gen 2, that ID has a different label. To avoid silently misidentifying held items, all held items are removed from the portable PK2, while their original ID, a `heldItemDropped` flag, and the unmodified native PK2 are retained in the archive. Original PK2 files can therefore still contain hack-specific item IDs.

The exporter uses the standard Gen 2 DV-derived shiny rule; a shiny sample has not been compared in-game. Gen 2 Gold/Silver Pokémon do not carry the same individual met-location and Poké Ball fields as later generations; no location or ball is invented. Stored encounter fields, when present, remain native and are not claimed to map custom locations. PC box levels use PKHeX's standard calculation. A 32 KiB raw save or that size with 44- or 48-byte trailing data is accepted; the footer is ignored for Pokémon extraction and not claimed to have verified RTC semantics. Checksums are required for battery saves. The game updated SRAM after a restart, at which point the standard checksum check failed until another in-game save; use a file captured immediately after saving and keep the original. Game file names, ROMs, state files and player records are not part of the public repository.

Implementation: `Historic/GbClassic.cs`, `Historic/MgbaShinRed.cs`, `Historic/gb-cobalt-blue.json`, `Engine.Host/StateExports.cs`; synthetic coverage: `ProfileChecks/GbStateChecks.cs`. The source-name audit is a local development tool outside the web repo. No game code or assets were copied into the project.
