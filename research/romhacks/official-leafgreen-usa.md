# Pokémon LeafGreen USA — official-game baseline and state recovery

The supplied official LeafGreen ROM fingerprint is SHA-256 `136d75e48ef4212f6188387d317964f9746ad46f54f2792289d1717064911f64`, mGBA CRC `1C12FD39`. Official game-save handling comes from upstream PKHeX. The local extension additionally offers read-only party/PC extraction for this exact mGBA version 7 build and selected FireRed/LeafGreen-layout battery export; other game revisions and emulator state formats are not implied.

One Eevee seeded from a different game was displayed, re-saved by this ROM in mGBA and reopened. Battery and live-state party bytes, nickname, OT, moves and PK6 identity match. This does not establish a native-caught fixture; PC handling is tested synthetically. Portable export uses conservative source-name mappings, standard PID-derived shiny/ability assumptions, standard Poké Ball only and unknown met location. Source bytes and metadata are retained. The original ROM/save files are not distributed in this repository.

The separately supplied old LeafGreen `.sav` is **not recovered**: its 64 KiB halves are duplicated, its sector signatures differ from the expected standard signature and normal checksums fail. A generic parser produced a bogus Pokémon, so no record should be trusted without independent recovery proof. This failure is not a fakemon exclusion and the seed test must not be presented as recovery of that old save. [Synthetic checks](../../src/PKHeX.Everywhere.ProfileChecks/VbaChecks.cs) cover selected battery and mGBA PC indexing. Browser chooser and download remain unverified.
